# Cucumber Test Tutorial

This repository contains an automated web testing project built with Java, Maven, Selenium, Cucumber, and TestNG. It validates the behavior of the SauceDemo (Swag Labs) e-commerce demo application through acceptance-style BDD scenarios.

## Project purpose

The goal of this project is to exercise key user flows in a web app by simulating real browser interactions and verifying expected outcomes. The tests cover authentication, product browsing, sorting, adding/removing products, checkout validation, order completion, and reset/logout flows.

## Test architecture

The project uses the Cucumber BDD style, where each feature file describes a business scenario and the corresponding step definitions implement the browser actions.

### Components

- `features/`: scenario definitions written in Gherkin
- `steps/`: Java classes with Given/When/Then step implementations
- `Run*.java`: test runners that execute specific feature files
- `CommonSteps.java`: shared browser actions and reusable validations

## Covered scenarios

The project includes automated tests for the following flows:

- Login success and failed login
- Locked-out user validation
- Product visualization
- Product details page
- Sorting by product name and price
- Add product from catalog
- Add product from product details
- Remove product from catalog
- Cart review
- Checkout mandatory data validation
- Successful checkout
- Reset app state
- Log out functionality
- Authentication error handling

Examples of feature files include:

- `LogIn.feature`
- `ProductVisualization.feature`
- `ProductPriceSortingLowHigh.feature`
- `CheckoutSuccess.feature`
- `ResetAppState.feature`

## How the tests work

Each scenario loads the SauceDemo web page, interacts with elements using Selenium selectors, and asserts the expected results through TestNG assertions.

The base flow is implemented in `CommonSteps.java`, which includes helpers such as:

- opening the login page
- entering credentials
- sorting products
- navigating to the cart
- clicking actions like Continue, Checkout, Finish, and Logout
- verifying error messages and cart count updates

## Setup requirements

Before running the tests, make sure you have:

- Java JDK installed
- Maven installed
- Google Chrome installed
- ChromeDriver available in the environment or compatible with the installed Chrome version

## Run the tests

From the project folder (`CucumberTestTutorial`), run:

```bash
mvn test
```

If you want to run a specific feature or runner class, you can use a Maven TestNG invocation pattern such as:

```bash
mvn test -Dtest=RunLogInTest
```

## Report generation

The project generates HTML and XML reports under the `test-output/` folder after execution. These reports help review failed steps and validation results.
